# Contributing

This project is still in very early stages, and has not yet reached the stage I would have wanted before going public. However, many people have requested that I share the codebase, so here it is!

In this spirit, contributions are not yet accepted. I'm still drafting up the next objectives with this app, and how to get there. When this is done, I'll make sure to update the contribution guidelines to accept external help.

In the meantime, feel free to fork the repo, and play with it on your end!

**You're always welcome to use the 'discussions' section on GitHub to share feedback, request features, or discuss the project with others!**
